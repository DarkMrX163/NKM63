# Краеведческий Квест: Нефтегорский район и Самарский край 🏛️

Интерактивный краеведческий веб-сайт и викторина для детей и взрослых на базе материалов Нефтегорского межпоселенческого краеведческого музея (nkm63.ru).

---

## 🚀 Быстрый запуск на ПК локально

### 1. Требования
- Установленный **Node.js** (версия 18 или новее). [Скачать Node.js](https://nodejs.org/)
- Установленный **Git**. [Скачать Git](https://git-scm.com/)

### 2. Клонирование и запуск
Откройте терминал (или командную строку / PowerShell) и выполните команды:

```bash
# 1. Клонировать репозиторий (замените ссылку на вашу)
git clone https://github.com/ВАШ_ЛОГИН/имя-репозитория.git

# 2. Перейти в папку проекта
cd имя-репозитория

# 3. Установить зависимости
npm install

# 4. Запустить локальный сервер разработки
npm run dev
```

После этого откройте браузер по адресу: **`http://localhost:3000`**

## 📤 Как загрузить проект на GitHub

Если вы хотите выложить проект в свой репозиторий на GitHub:

1. Создайте новый публичный или приватный репозиторий на [GitHub.com](https://github.com/new) (не инициализируйте README, `.gitignore` или лицензию, если они уже есть в проекте).
2. В терминале в папке проекта выполните:

```bash
git init
git add .
git commit -m "Initial commit: Краеведческий Квест"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

## 🌐 Бесплатный деплой и публикация на GitHub Pages

В проекте уже настроен автоматический **GitHub Actions Workflow** (`.github/workflows/deploy.yml`).

Чтобы сайт автоматически публиковался в интернете при каждом обновлении кода:

1. Перейдите в ваш репозиторий на GitHub.
2. Нажмите **Settings** (Настройки) -> **Pages** (в меню слева).
3. В разделе **Build and deployment** -> **Source** выберите:
   👉 **`GitHub Actions`** (вместо "Deploy from a branch").
4. При следующем `git push` сайт автоматически скомпилируется и станет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

## 🛠️ Сборка для продакшена (Production Build)

Если вы хотите собрать готовый статический сайт для любого хостинга:

```bash
npm run build
```

Готовые файлы будут находиться в папке `dist/`. Вы можете загрузить их на любой веб-сервер.

Для запуска полноценного Node.js сервера со встроенным backend-прокси:
```bash
npm start
```

## 🔑 Переменные окружения (`.env`)

Для работы ИИ-эксперта (интеграция с Google Gemini API) вы можете скопировать файл `.env.example` в `.env` и указать ваш ключ:

```env
GEMINI_API_KEY="ваш_ключ_gemini_api"
```

*Примечание: Если ключ не указан, ИИ-эксперт работает в режиме умных краеведческих подсказок по умолчанию.*
